# Getting started

1. VARS in AAP Survey: 
   - hostnames: TEXTAREA - List format ip or FQDNs
   - login_user: TEXT - Username to connect
   - login_password: PASSWORD - Password Type 
   - serv_name: TEXT - Service Name to restart 
   - mailid: TEXT - User's email to send the notification

2. VARS to be embedded in Job Template:
   - from_email: AutomationNotificatuions@localhost
   - smtp_server: Your SMTP Host
   - port: Your SMTP Port
